## NetSentinel for Windows x64

Install the x64 Npcap runtime, then run **NetSentinel-0.1.1-demo-windows-x64-setup.exe**. This unsigned per-user Electron installer includes the React interface, local service and native capture worker. [Npcap installation guide](https://npcap.com/guide/npcap-users-guide.html)

- Capture live Ethernet-format traffic through Npcap. Inspect packets and filter by protocol or text. Scrolling through older packets keeps the inspected row in place while capture continues.
- Choose a live history of 5,000, 10,000, 30,000 (default), or 50,000 records. Session Details reports output queue losses and intentional history evictions separately.
- Save retained, filtered, or selected packet metadata as local CSV or JSON archives. Open **Logs** to browse saved files, import external logs, or reopen an archive after restarting. Archives are stored in the Windows Documents folder under **NetSentinel_Logs**.
- Review device inventory, trust preferences, traffic statistics, security detections and alert history. Optional local administrator authentication protects sensitive settings and destructive actions.

Windows x64 is the verified desktop target. Linux packaging and live Linux capture remain incompletely verified. Live history is bounded in memory; continuous disk recording is unavailable. Only an explicit export saves packet metadata to disk. Raw monitor-mode Wi-Fi decoding and driver-level loss measurement are outside this release.
